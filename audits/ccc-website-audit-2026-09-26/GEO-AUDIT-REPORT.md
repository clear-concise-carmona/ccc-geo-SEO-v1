## 3. Methodology and evidence classes

- **Direct observation (fetch), 2026-09-27 (EV-038):** raw HTML, response headers, JSON-LD, robots.txt, sitemap.xml, llms.txt as served to a desktop browser user agent. Strongest class in this workspace.
- **Status probes (HEAD), 2026-09-27 (EV-039, EV-043):** status code and Location only; no bodies, no canonicals.
- **Direct observation (index), 2026-09-26 (EV-002 to EV-031):** titles and snippets. Now known to lag the site by weeks; used only where no live observation exists (built-in domain content, third-party profiles).
- **Owner-provided documentation (EV-032 to EV-035):** statements of intent and reported state as of April to May 2026. Not live observation. Where it conflicts with the live site (the $8,000 price), the live site is treated as current and the conflict is reported.
- **Tool heuristics (EV-042, EV-038):** the toolkit's citability_scorer.py run on saved HTML; fetch_page's has_ssr_content flag; robots.json ai_crawler_status. Diagnostic only. A citability score is a passage-structure heuristic, not a measurement of citations.
- **Primary-source documentation (EV-043):** schema.org type pages and Google Search Central's FAQPage documentation, reachable this pass.
- **Hypotheses:** labeled where used (query map demand, conversion friction, the mailbox-address reading, competitor positioning).

Every finding cites evidence IDs that resolve to files under evidence/ (evidence/evidence-index.md). CLM- IDs resolve to BUSINESS-CLAIMS-INVENTORY.csv, ISS- to PRIORITIZED-BACKLOG.csv, FACT- to CANONICAL-BUSINESS-FACTS.md.
